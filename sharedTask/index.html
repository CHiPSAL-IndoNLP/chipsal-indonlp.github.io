Call for Participation: CHiPSAL–IndoNLP 2027 Shared Tasks at COLING 2027

We invite researchers, students, and practitioners working on NLP, multilingual AI, education, and public health to take part in two shared tasks advancing Natural Language Processing for low-resource languages as part of the Joint CHiPSAL–IndoNLP Workshop at COLING 2027 (May 14–15, 2027, Macau, China).

Shared Tasks

Task 1 NESA: Nepali Essay Scoring

Build an automated essay scoring system to score student essays written in Nepali on a 1–10 scale. Submissions are evaluated and ranked using Quadratic Weighted Kappa (QWK).

  • Competition (Codabench): https://www.codabench.org/competitions/18661/
  • Task Details & Data (GitHub): https://github.com/shucoll/chipsal27-essay-scoring

Task 2 HealthMisInfo: Health Misinformation Detection

Develop a classification system to identify health-related posts as either factual or misinformation. Submissions are evaluated and ranked by macro F1.

  • Competition (Codabench): https://www.codabench.org/competitions/18660/
  • Task Details & Data (GitHub): https://github.com/shucoll/chipsal27-health-misinfo

Schedule & Participation Details

  • Development Phase: Currently underway. Training/development datasets and baseline details are available via the respective GitHub repositories and Codabench competition pages above.
  • Test Data Release: Scheduled for January 4, 2027.
  • System Description Papers: Participants are strongly encouraged to submit a system description paper to the CHiPSAL–IndoNLP 2027 workshop proceedings (see the Call for Papers page for formatting guidelines), though submitting a paper is not required to participate in the shared tasks.
